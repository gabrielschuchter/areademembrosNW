# Changelog

## 1.0.0 — 2026-08-05

### Preparado para publicação

- Criação de uma release completa com os 19 arquivos da Kiwify.
- Preservação integral da ordem e das fileiras visíveis.
- Remoção somente da instância vazia `bNbbqY`.
- Redução do template principal para 25 seções.
- Correção do CSS malformado e dos imports tardios.
- Adoção de Poppins com fallback de sistema.
- Criação do design system `nw-*`.
- Redesign de banner, continuar assistindo, boas-vindas, catálogo, extras, fileiras e login.
- Títulos permanentes e experiência touch-first.
- Progresso textual, estados de acesso e fallbacks de imagem.
- Links externos com `noopener noreferrer`.
- Paridade de chaves PT, EN e ES.
- ESTUDE! classificado corretamente como e-book de organização de estudos.
- Suporte adicionado ao final da última fileira.
- Validadores atualizados para verificar a release pronta.
- README ampliado com o procedimento completo de implementação e rollback.

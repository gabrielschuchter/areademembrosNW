# ADR 0003 — Sem JavaScript customizado

**Status:** aceito.

## Contexto

A documentação oficial informa que JavaScript customizado não é suportado no tema.

## Decisão

Não projetar recursos que dependam de JS próprio. Utilizar apenas componentes nativos, Liquid, HTML, CSS, Tailwind e atributos reconhecidos pela Kiwify/Embla.

## Consequências

Busca dinâmica, persistência própria, API externa e interações complexas ficam fora do escopo do tema.
